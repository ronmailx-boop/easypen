# Политика использования файлов cookie

**Последнее обновление:** 15 октября 2026 г.

## 1. Использует ли Приложение файлы cookie?

**Нет.** Приложение EasyPen не создаёт файлы cookie и не использует их для отслеживания, рекламы, аналитики или каких-либо иных целей.

Приложение не загружает компоненты рекламных сетей и социальных сетей, а также шрифты или библиотеки с других сайтов. Единственный внешний компонент – инструмент измерения посещений Cloudflare Web Analytics, который не создаёт файлы cookie и ничего не сохраняет в браузере (подробнее – в [Политике конфиденциальности](privacy-policy.md), раздел 6). Поэтому третьи лица через него также не создают файлы cookie.

## 2. Локальное хранилище в браузере

Для работы Приложение сохраняет информацию в браузере с помощью технологий локального хранения. Эта информация **не отправляется ни на какой сервер** и используется только Приложением:

| Технология | Что хранится | Цель | Срок хранения |
|---|---|---|---|
| IndexedDB | Сохранённые подписи (до 3) | Повторное использование подписи, если вы этого захотите | Пока вы их не удалите |
| IndexedDB | Документ, открытый для редактирования | Отображение и редактирование документа | До возврата на главный экран |
| Cache Storage (Service Worker) | Файлы Приложения | Быстрый запуск и работа без подключения к интернету | До обновления версии или очистки данных сайта |
| localStorage | Настройки: инструмент и цвет рисования, добавлять ли ссылку на EasyPen в сообщение при отправке, было ли уже показано приглашение поделиться приложением | Запоминание вашего выбора | До очистки данных сайта |
| sessionStorage | Язык интерфейса, если он выбран ссылкой (например, `?lang=ru`) | Показ Приложения на выбранном языке при переходе между экранами | До закрытия вкладки |

## 3. Согласие

Описанное выше локальное хранение строго необходимо для предоставления запрошенного вами сервиса. Оно не содержит идентифицирующей информации и не используется для отслеживания или рекламы. Поэтому Приложение не запрашивает согласие на использование файлов cookie.

Если в будущем будут использоваться файлы cookie или необязательные инструменты, эта политика будет обновлена, а ваше согласие будет запрошено заранее, как того требует закон.

## 4. Управление и удаление

- **Сохранённые подписи:** любую подпись можно удалить на экране «Мои подписи».
- **Вся локальная информация:** её можно удалить через настройки браузера. Например, в Chrome для Android: Настройки → Настройки сайтов → Все сайты → выберите сайт → Удалить и сбросить.
- **Удаление Приложения** с устройства также удаляет хранящуюся в нём информацию.
