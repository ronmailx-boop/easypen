## 3. התאמות הנגישות באפליקציה

### מבנה ותצוגה

- ממשק בעברית מלאה, בכיוון ימין-לשמאל (RTL), המותאם לטלפון נייד.
- אפשר להגדיל את התצוגה בתנועת צביטה או בהגדרות הדפדפן, והאפליקציה אינה חוסמת זאת.
- ניגודיות צבעים בהתאם לדרישות רמה AA בטקסטים ובכפתורים.
- כפתורים ואזורי מגע בגודל של 44 פיקסלים לפחות.
- האפליקציה מכבדת את הגדרת "הפחתת תנועה" של מערכת ההפעלה.

### קוראי מסך

- לכל כפתור המוצג כאייקון בלבד יש תווית טקסט לקורא המסך.
- שדות הטופס מקושרים לתוויות שלהם.
- הודעות שגיאה והודעות מצב מוקראות אוטומטית.
- חלונות קופצים מבוססים על רכיב `dialog` התקני: הפוקוס עובר אליהם בפתיחה, ומקש Esc סוגר אותם.

### הפעלה במקלדת

כל פעולות העריכה במסמך זמינות גם במקלדת, כחלופה לגרירה במגע או בעכבר:

| מקש | פעולה |
|---|---|
| Tab | מעבר בין הכפתורים, החתימות ותיבות הטקסט במסמך |
| חיצים | הזזת החתימה או תיבת הטקסט הנבחרת |
| Shift + חיצים | הזזה בצעד גדול |
| + או − | הגדלה או הקטנה של החתימה, או של גודל הגופן בתיבת טקסט |
| Enter | עריכת תיבת הטקסט הנבחרת |
| Delete | מחיקת הפריט הנבחר |
| Esc | יציאה מעריכת טקסט, ביטול הבחירה או סגירת חלון |

## 4. מגבלות ידועות

למרות מאמצינו, ייתכן שחלקים מסוימים עדיין אינם נגישים במלואם:

- **ציור חתימה** דורש תנועת אצבע, עט או עכבר. **חלופה:** בחירה ב"הוסף טקסט" והקלדת השם במקום החתימה.
- **תוכן מסמכי ה-PDF** מוצג כתמונה של העמוד, ואינו מוקרא על ידי קורא מסך בתוך האפליקציה. נגישות תוכן המסמך עצמו תלויה ביוצר המסמך.
- **שיתוף קבצים לאפליקציה** מאפליקציות אחרות זמין רק במכשירים ובדפדפנים שתומכים בכך (בעיקר כרום באנדרואיד). **חלופה:** העלאת הקובץ דרך הכפתור "העלה מסמך".
