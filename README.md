# EasyPen - חתימה דיגיטלית

PWA לחתימה על מסמכי PDF ותמונות מהנייד, בעברית ובאנגלית. כל העיבוד מתבצע בדפדפן — הקבצים לא נשלחים לשום שרת.

## יכולות

### פתיחת מסמך
- **PDF:** "העלה מסמך" במסך הבית, או שיתוף לאפליקציה מוואטסאפ, מג'ימייל או מכל אפליקציה אחרת (Web Share Target, אחרי התקנת האפליקציה באנדרואיד).
- **איחוד קבצים:** עד 20 קבצים ביחד — כמה קבצי PDF, תמונות JPG ו-PNG, או שילוב שלהם — בהעלאה או בשיתוף (גם מהגלריה), הופכים ל-PDF אחד בסדר שנבחרו: כל העמודים של כל PDF, ועמוד לכל תמונה.
  - **בלי פגיעה באיכות:** עמודי PDF מועתקים כמו שהם (הטקסט נשאר טקסט שאפשר לחפש ולהעתיק); JPG נכנס כמו שהוא, בלי דחיסה מחדש; PNG נשמר בלי אובדן, כולל שקיפות.
  - **הוספה למסמך פתוח:** כפתור "הוספת קבצים או תמונות" בסוף המסמך מוסיף עוד PDF או תמונות כדפים בסוף, גם אחרי שכבר חתמתם (החתימות נשארות במקומן).
  - **שמירה בלי חתימה:** מסמך מאוחד אפשר לשמור ולשתף גם בלי להוסיף לו כלום (הקובץ נקרא `…-מאוחד.pdf`).
  - **PDF מוצפן** לא מאוחד עם קבצים אחרים (הודעה מסבירה; לבד הוא נפתח כרגיל). שדות של טופס למילוי נשארים כמו שהם נראים, אבל ייתכן שלא יהיו פעילים.
  - **תמונה שצולמה לרוחב** מוצגת ישרה (סימון הסיבוב של המצלמה הופך לסיבוב העמוד).
  - **סדר העמודים:** על כל עמוד בעורך יש מספר ("3/4") וחצים למעלה/למטה; החיצים נשארים מתחת לאצבע אחרי כל הזזה. השמירה יוצאת בסדר שעל המסך.

### חתימה
- **ציור חתימה** באצבע, בשחור או בכחול, או **בצבע שנדגם מהמסמך עצמו:** "דגימה" ← גוררים אצבע על המסמך עם זכוכית מגדלת (פי 4) שמראה בדיוק את הנקודה והצבע ← "בחירה". כל צבע נקלט, גם רקע. החלפת צבע צובעת את כל החתימה.
- **"החתימות שלי":** עד 3 חתימות שמורות במכשיר לשימוש חוזר, עם עריכה ומחיקה.
- **מיקום וגודל:** גרירה, ידית שינוי גודל בפינה, וסליידר גודל בסרגל של החתימה הנבחרת (5%–100% מרוחב העמוד).

### טקסט וציור
- **טקסט:** הקשה במקום בעמוד, הקלדה בעברית או באנגלית (הכיוון נקבע לפי מה שמקלידים), שינוי גודל גופן, גרירה.
- **ציור חופשי:** עט, טוש או מרקר הדגשה, 7 צבעים, עובי 1–20, ביטול קו אחרון. אצבע אחת מציירת, שתי אצבעות מגדילות וגוללות. אפשר להסתיר את מגש הכלים, ו"מצב גלילה" מאפשר לגלול באצבע אחת בלי לצייר.

### תצוגה
- **הגדלה בצביטה** עד פי 4 בתוך האפליקציה (Ctrl+גלגלת במחשב); הסרגלים נשארים קבועים בתחתית ובראש המסך.
- **עמודים בגלילה אנכית**, עם ציור מחדש חד אחרי הגדלה. טקסט לטיני בתוך ה-PDF מוצג נכון גם בממשק העברי.

### שמירה ושיתוף
- **"שמור ושתף"** משטח את החתימות, הטקסט והציור לתוך ה-PDF ופותח את תפריט השיתוף של הטלפון (או מוריד את הקובץ). לפני כן נפתח חלון לשינוי שם הקובץ; השם המוצע: `<שם>-חתום.pdf` (`-signed.pdf` באנגלית).
- **פרטיות:** הכול מתבצע במכשיר — הקבצים לא נשלחים לשום שרת. המסמך הפתוח נמחק בחזרה למסך הבית.

### כללי
- **עברית ואנגלית** לפי שפת המכשיר (פירוט בסעיף "שפות").
- **אפליקציה להתקנה (PWA)** שעובדת גם בלי חיבור לרשת.
- **מסמכים משפטיים** בעברית ובאנגלית: מדיניות פרטיות, תנאי שימוש, מדיניות עוגיות והצהרת נגישות.
- **נגישות:** כל פעולות העריכה זמינות גם במקלדת (חיצים, +/−, Enter, Delete, Esc), תוויות לקוראי מסך, כפתורים בגודל 44px לפחות.
- **תצוגה מקדימה בשיתוף קישור** (וואטסאפ וכו') עם האייקון של האפליקציה.

## זרימה (טכני)
1. **מסך הבית** (`js/home.js`): PDF אחד נשמר כמו שהוא ב-IndexedDB; כמה קבצים, או תמונה, מאוחדים ל-PDF אחד ב-`js/combine-pdf.js` (pdf-lib נטען רק כשצריך): PDF ב-`copyPages` (העמודים כמו שהם; PDF מוצפן נדחה), JPG ב-`embedJpg` (DCTDecode, הבייטים המקוריים; תג EXIF Orientation מאופס והעמוד מקבל `/Rotate`), PNG ב-`embedPng` (Flate + SMask). הצד הארוך של העמוד 842pt — לא משפיע על הרזולוציה. המסמך נשמר עם `combined`.
   קבצים ששותפו: PDF אחד נפתח ישר בעורך; כמה קבצים או תמונות — `sw.js` שומר אותם ב-IndexedDB (`shared-files`) ומפנה ל-`index.html?source=share-files`, ומסך הבית מאחד אותם באותה דרך.
2. **עורך** (`js/viewer.js`): pdf.js מרנדר עמודים לפי הצורך (קנבס `dir="ltr"`). חתימות וטקסט נשמרים בקואורדינטות יחסיות לעמוד, ציור כ-SVG בנקודות PDF. הגדלה: `--zoom` על `.pages` ו-`touch-action: pan-x pan-y` (זום הדפדפן חסום, `minimum-scale=1` כדי שהסרגלים לא יתרחבו). סדר עמודים: סדר ה-DOM; `data-page` נשאר המספר המקורי. דגימת צבע: ממוצע 3×3 פיקסלים מקנבס העמוד מתחת לטבעת.
3. **ייצוא** (`js/pdf-handler.js`): pdf-lib מצייר את החתימות, הטקסט (כ-PNG) והציור (PNG בגודל העמוד) על העמודים המקוריים, ואז מסדר את אותם אובייקטי עמוד בסדר שעל המסך. PDF מוצפן נבנה מחדש מתמונות של העמודים.

## שפות
השפה נבחרת לפי שפת המכשיר, בלי כפתור החלפה: `he`/`iw` → עברית מימין לשמאל, כל שפה אחרת → אנגלית משמאל לימין.
כל הטקסטים בשתי השפות נמצאים ב-`js/i18n.js` (`t(key, vars)`). העברית כתובה גם ב-HTML, ובמכשיר באנגלית אלמנטים עם `data-i18n` / `data-i18n-aria` / `data-i18n-alt` מקבלים את הטקסט באנגלית. עמוד עובר לאנגלית רק כשמסומן `<html data-i18n-page>`.
טקסט חדש בממשק = מפתח חדש בשתי השפות (בדיקת e2e נכשלת אם חסר אחד). המסמכים המשפטיים באנגלית ב-`docs/legal/en/` — כל שינוי במסמך עברי צריך להיכנס גם לגרסה האנגלית.

## פיתוח מקומי
אתר סטטי, ללא build:
```bash
npm run serve        # או: python3 -m http.server 8080
```
Service Worker ו-Share Target דורשים HTTPS (או localhost). Share Target עובד רק אחרי התקנת ה-PWA (אנדרואיד/כרום).

## בדיקות
```bash
npm install && npm test
```
פירוט ב-[`tests/README.md`](tests/README.md). `package.json` משמש לבדיקות בלבד — האתר עצמו לא דורש build.

## פריסה
כל הנתיבים יחסיים, כך שהאתר עובד גם בשורש הדומיין וגם תחת תת-תיקייה.

- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Cloudflare Workers** (https://easypen.vplusstudio.app, וגם https://easypen.ronmailx.workers.dev): פריסה דרך GitHub Actions — `.github/workflows/deploy-cloudflare.yml` מריץ `wrangler deploy` בכל push ל-`main` (או ידנית מלשונית Actions). ההגדרות ב-`wrangler.jsonc`, ו-`.assetsignore` מוציא מהפריסה את כל מה שאינו חלק מהאפליקציה.
  הגדרה חד-פעמית:
  1. Cloudflare → My Profile → API Tokens → Create Token → תבנית **Edit Cloudflare Workers** → Account Resources: החשבון, Zone Resources: **All zones** → Create Token.
  2. GitHub → Settings → Secrets and variables → Actions → New repository secret בשם `CLOUDFLARE_API_TOKEN`.
  3. Actions → Deploy to Cloudflare → Run workflow.

  חיבור Git דרך לוח הבקרה של Cloudflare לא עבד (לולאה במסך Connect GitHub), ולכן לא משתמשים בו.

בכל שינוי בקבצי האפליקציה יש להעלות את המספר ב-`js/version.js`, כדי שהמשתמשים יקבלו את הגרסה החדשה.
