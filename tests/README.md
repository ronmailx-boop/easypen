# בדיקות EasyPen

בדיקות End-to-End ב-Playwright (Chromium, מסך נייד 390px), עם מריץ הבדיקות המובנה של Node (`node:test`).

## הרצה
```bash
npm install
npx playwright install chromium   # פעם אחת, אם הדפדפן לא מותקן
npm test
```
אפשר להפנות לדפדפן קיים עם `CHROMIUM_PATH=/path/to/chromium npm test`.

## מה נבדק
| בדיקה | מה היא מוודאת |
|---|---|
| home screen | קובץ שאינו PDF נדחה עם "כרגע נתמכים קבצי PDF בלבד" |
| non-PDF content | קובץ בשם `.pdf` שאינו PDF אמיתי מציג שגיאה ולא קורס |
| exact position | חתימות וטקסט (עברית/אנגלית, רב-שורתי) מיוצאים **בדיוק** במקום שבו הוצבו — בעמוד רגיל, מסובב 90°/270° ועם CropBox |
| empty text / delete | תיבת טקסט ריקה נמחקת, מחיקת פריט עובדת, אין ייצוא בלי תוכן |
| cross-page drag | גרירת חתימה לעמוד אחר מעבירה אותה לעמוד הזה |
| my signatures | עד 3 חתימות, עריכה, מחיקה, שמירה כ-PNG |
| service worker | Share Target (סימולציית שיתוף מוואטסאפ), דחיית docx בשיתוף, עבודה אופליין |

### איך נבדק מיקום מדויק
ה-PDF המקורי והמיוצא מרונדרים ב-pdf.js באותו קנה מידה, ומחושב האזור שבו הפיקסלים השתנו.
הבדיקה מוודאת שהאזור הזה נמצא בתוך מיקום האלמנט כפי שהוצג בעורך (סבולת 1.5%) וממלא את רובו.

## קבצים
- `e2e.test.js` — הבדיקות
- `helpers/server.js` — שרת סטטי שמגיש את האתר תחת `/easypen/`, כמו GitHub Pages (תופס נתיבים אבסולוטיים שבורים), ומחזיר 405 ל-POST כמו GitHub Pages
- `helpers/fixtures.js` — יוצר PDF בדיקה עם 4 סוגי עמודים
